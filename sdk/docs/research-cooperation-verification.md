# ScienceEvolve 搜索树、Gate 与异步 Main 验证记录

本次实现覆盖 Web/Server 与 SDK/CLI 的共同核心及各自入口。公开契约分别见 [搜索树](search-tree.md)、[Gate](workflow-gate.md)、[异步 Main](main-assistance.md)。没有修改现有运行数据、调用真实模型、推送或部署。

| 方案验收项 | 实现与局部验证 |
|---|---|
| ST-01～ST-03 | 可选启用、空根与初始文件快照、嵌套方向、单根无环校验；Web 配置与运行视图 |
| ST-04～ST-07 | 候选状态与证据、独立 Git 元数据提交、真实版本保留、历史查询、幂等回执与版本冲突 |
| ST-08 | 按需上下文、MCP、SDK API 和 CLI；共同源码校验一致 |
| GT-01～GT-04 | 原 Agent 执行代码、配置 Agent 检查与独立决策者、自定义结果、三条出边、负面反馈正常交付 |
| GT-05～GT-06 | 绑定真实 Shell 调用和输出；拒绝自报替代、错误调用、错误选路、缺字段、截断和执行失败 |
| GT-07～GT-08 | 来源、输入及配置冻结；恢复保留已知结果，避免重复下游激活；串行、根流程与 scoped 配置/执行接入 |
| MA-01～MA-04 | 请求即时返回、Main 独立执行并串行处理、答复回到原任务/Session、真实原生收件证明、Loop 任务隔离 |
| MA-05～MA-08 | 待答复不阻止交回，正常 Main 路由保持原契约；失败、暂停、服务中断、替换 Session 与迟到答复保留真实状态 |

已执行的局部检查包括：

- Server 搜索树、Gate、Main 持久化单元测试，原生输入校验；Main 的原 Session 不匹配分支另有回归。
- Server 调度器联测：串行 Main 正常答复、失败及迟到答复，根节点与协作组直接请求 Main，多请求顺序处理，服务中断后停止核验且不重复 Main 调用；同时回归根/串行 Gate 与正常 Main 路由。
- 独立 MCP 进程验证工具发现、请求响应及通知失败不覆盖原工具成功结果；Codex 协议进程验证 `turn/steer` 绑定原 turn，原生拒收不伪造成功或重启请求方。
- Web 搜索树、Gate 配置/展示及 Main 接收状态展示测试；Server、Web、SDK 类型检查通过。
- SDK 相同核心测试、宿主快照与重连读取测试通过。SDK 测试执行了规定的运行时来源、资源复制及命名检查。
- `sync-shared-core --check` 校验 338 个映射文件，SDK `--check-source` 校验 336 个来源文件，共同核心无新增漂移。

局部扩展检查发现的三条既有失败，在 Gate 修改前的工作区基线上也可复现：同一 Agent 跨兄弟组队列的 revision 断言、已领取管理者之后的子组准备 revision 断言、复用子组最终同步证明时的完成状态断言。这些问题未作无关修改；局部通过不表示全量测试通过。

未执行全量测试、完整打包或真实 Codex/Pi/DSH 模型端到端运行。原生接收依赖各 Harness 的真实事件与可接收边界；不存在后续边界时保留待投递或迟到状态。Gate 不支持的组合在配置边界明确拒绝，具体范围见 Gate 文档。搜索树不自动远端备份或 push；没有新增隐式实验、自动重派、评测隔离或权限扩大。

原工作区已有的修改保持未提交；本次按功能分别提交，每个提交仅包含本功能增量。
