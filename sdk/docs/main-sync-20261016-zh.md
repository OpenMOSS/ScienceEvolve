## 使用与数据目录

源码更新后执行 `npm ci` 和 `npm run build`；全局 CLI 链接安装使用 `npm run install:cli`。
独立安装用户需要重新打包和安装 `scienceevolve-sdk-0.1.1.tgz`。
新任务使用新的独立绝对路径 `dataDir`；旧目录的来源版本锁仍要求显式迁移，不能手改标记绕过。
本轮没有升级运行中的科研实验、迁移旧状态或发布 npm 包。

先前记录见 [2026-10-14 同步说明](main-sync-20261014-zh.md)，其中历史测试数字不作为本轮验收结果。
