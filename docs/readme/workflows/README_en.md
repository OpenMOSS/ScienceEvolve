# ScienceEvolve Workflow atlas

[← README](../../../README.md#examples) · [简体中文](README.md) · [Method mapping](../../../example/METHODS.md)

23 examples: 23 routing overviews and 36 stage/group details. Start with the detail pages for large workflows; ScientistTwo has nine stage views.

These are documentation presentations rendered with the actual frontend CanvasWorld, CanvasNodes, CanvasEdges, semantic adapter and router, with export/import validation. They use separate print layouts, **100% canvas zoom, 16 CSS-pixel node titles and 1.5 device scale**; they are not screenshots of the complete application window. Long names wrap instead of being truncated. Stage views contain only real edges between selected nodes; consult the overview for cross-stage edges.

The method guides are explanatory, not executable routes. Main-centered scheduling is not a complete paper-method diagram. Each page states synchronous/serial adaptations, tool/state boundaries, external experiments, and unverified capabilities. **No models or scientific experiments were run. Static validation does not reproduce paper results.**
