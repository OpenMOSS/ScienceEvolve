# ScienceEvolve Scientific Skills

[← Project README](../../README.md#scientific-skills) · [简体中文](README_zh-CN.md)

**875 scientific method Skills across 12 research areas**, distilled from over 70,000 published papers. Choose Skills that match the research question and configure them for the relevant Agents.

Each Skill defines when to use it, required inputs, a research procedure, expected outputs, validation gates, claim boundaries, and failure handling. Skills guide the method; data, tools, and experimental resources are supplied by the project.

These directories share the existing built-in Skill location with the general research, writing, review, and platform Skills. Each scientific Skill has a domain-specific unique name; its runtime reference is `builtin:<name>` from the `SKILL.md` frontmatter.

In the Web editor, select an Agent and add a Skill through its existing Skills control. In an SDK workflow, set the Agent’s `skills` or `autoSkills`. Fixed Skills load on every call; automatic Skills are offered when supported by the selected Harness.

The SDK build includes this directory in `assets/skills`. License: [MIT](SCIENTIFIC_SKILLS_LICENSE).
