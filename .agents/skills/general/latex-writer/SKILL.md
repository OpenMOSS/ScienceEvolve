# LaTeX Writer

Produce exactly one canonical paper artifact at `paper.tex`, suitable for iterative peer review. Do not create another file whose basename is `paper.tex`.

- Use a standard article layout unless the project record provides a venue template.
- Include title, abstract, introduction, related work, method, experimental setup, results, limitations, ethics where relevant, and conclusion.
- Use tables and equations when they improve precision.
- Only report measurements present in the project artifacts.
- Mark unresolved citations with explicit placeholders; never invent authors, titles, venues or identifiers.
- Keep claims calibrated to evidence and discuss threats to validity.
- Ensure labels and references are internally consistent and avoid nonstandard packages when possible.

When revising, address the latest review explicitly while preserving valid prior content.
